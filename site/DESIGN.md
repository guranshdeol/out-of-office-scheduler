# Site design reference

The landing page follows the **Linear** style from [Refero Styles](https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1) ("midnight precision instrument"). Key rules applied:

- **Canvas** `#08090a`, cards `#0f1011`, elevated `#161718`; borders are hairlines in `#23252a` / `#383b3f`, never shadows.
- **Type**: Inter Variable with `cv01`, `ss03`, `zero`; weights 400 / 510 / 590 only. Display 64–72px at `-0.022em`, body 16px / 1.5. Mono (JetBrains Mono) only for versions, file names and step numbers.
- **Color**: headings `#ffffff`, body `#d0d6e0`, muted `#8a8f98`. **Acid lime `#e4f222` is used only for the single primary download action in a view.** Supporting accents (pulse green, iris violet) appear only in small status chips.
- **Shape**: buttons and inputs 6px, cards 12px, pills 9999px. No other radii.
- **Rhythm**: 1200px max width, 96px between sections, 24px card padding, 8px element gaps.
- **Imagery**: real product screenshots in hairline-framed cards; the only gradient is the atmospheric floor under the hero screenshot.
- **Layout**: left-aligned hero, then alternating text/image rows. No 3-column card grids.
